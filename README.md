# Keycat templates

Starting points for taking payments with [Keycat](https://keycat.net). Each
template is a complete app in its own folder, built on
[`@keycatpay/sdk`](https://www.npmjs.com/package/@keycatpay/sdk).

| Template | What it is |
| --- | --- |
| [`commerce`](./commerce) | A Next.js storefront with a catalog, a cart, hosted checkout, an order page and a verified webhook route. |

Each folder's README covers setup and deployment. The integration itself is
documented at [docs.keycat.net](https://docs.keycat.net).
